# 작은 섬 · Diorama

실제 WebGL 3D 기하로 구성한 로컬 웹사이트입니다. 집·등대·부두, 그림자, 안개, 장소별 설명을 포함합니다.

## 실행

Node.js로 `node server.cjs`를 실행한 뒤 http://127.0.0.1:4173 을 엽니다. npm 설치는 필요하지 않습니다. Three.js 0.170.0은 로컬에 포함하며, 글꼴은 네트워크가 없으면 시스템 글꼴로 대체됩니다.

## 현재 조작

- 드래그: 수평 회전 및 상하 시점 변경
- 휠: 부드러운 확대·축소
- 흰색 지점 또는 장소 버튼: 이야기 패널 열기
- 자동 회전 토글, 시점 초기화, Escape로 패널 닫기
- 방향키 좌우: 회전, + / -: 확대·축소

## 레퍼런스 조사 · 2026-10-28

https://studio-penumbra.com/diorama-island/

브라우저에서 바깥 영역 드래그로 장면이 회전하고 휠로 확대되는 것을 확인했습니다. 물 블록 내부 드래그는 카메라 회전과 구분되며 물 표면이 크게 출렁이는 모습을 확인했습니다.

사이트의 조작 안내에는 다음이 표시됩니다.

> 구름·고래를 눌러 보세요 · 클릭: 물결 · 블록 드래그: 젤리 · 바깥 드래그: 회전 · 휠: 확대 · 우클릭 드래그: 이동

구름·고래 클릭의 구체적 결과와 우클릭 이동은 이번 조사에서 직접 검증하지 않았습니다. 물 클릭의 개별 파문도 상시 파도와 구분해 확정하지 않았습니다.

설정 패널에는 젤리 복원력·감쇠·마우스 반응·물 출렁임, 물결 지속, 파도 높이, 피사계 심도·틸트 시프트·보케 등의 조절 항목이 있습니다. 이는 작은 모형을 만지는 느낌을 조정하는 요소입니다. 정확한 물리 상수나 관성 구현은 소스 분석 없이 단정할 수 없습니다.

현 버전은 회전·확대를 우선 구현한 기반입니다. 물 클릭 파문, 물 블록 젤리 변형, 우클릭 이동, 구름·고래 반응은 아직 구현하지 않았습니다.

검증: JavaScript 구문 검사 통과. 작업 환경의 미리보기 브라우저에서 localhost 접속이 시간 초과되어 실제 렌더링과 모바일 동작은 미검증입니다.
