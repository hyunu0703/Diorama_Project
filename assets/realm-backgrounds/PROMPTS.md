# Realm backgrounds v1

Generated using the built-in image_gen tool. Day uses the generated night image as its composition and lighting edit reference.

## Night

Use case: stylized-concept. Create ONE standalone landscape 16:9 wallpaper image for the NIGHT realm of a celestial day/night chess diorama. Full-bleed immersive sky environment, no chessboard, no pieces, no floor or terrain, no frame, no text. Luxurious cinematic atmospheric cloudscape: deep midnight sapphire and indigo sky, delicate tiny silver stars and restrained four-point glints, softly sculpted voluminous clouds along the lower third, luminous cool blue moonlight on cloud edges, rich dark clear negative space in upper half. The cloud horizon sits precisely at the lower third; gently receding cloud layers extend to both side edges, suitable for pairing side-by-side with a matching daylight sky wallpaper. Sophisticated photorealistic fantasy matte painting, fine realistic vapor, elegant jewel tones, soft light, high detail, no gigantic celestial objects, no buildings, no characters. Output only a single night image, not a comparison, not a collage.

## Day

Use case: lighting-weather. Asset type: standalone DAY realm wallpaper paired with the night wallpaper shown in Image 1. Input Image 1 is the edit target and composition reference. Transform this exact cloudscape from midnight into luminous clear daylight. Preserve the exact 16:9 composition, viewpoint, cloud silhouettes, cloud positions, horizon level and depth, so the two images can be used as corresponding night/day backgrounds in a celestial chess diorama. Replace midnight sky and every star / Milky Way with beautiful clear cerulean and pale azure daytime sky. Relight clouds with warm soft golden-white sunlight, glowing ivory upper surfaces and very gentle pale blue shadows. Bright, airy, refined cinematic photorealistic fantasy matte painting, richly detailed natural vapor. Single full-bleed DAY image only. No split screen, no night elements, no board, no chess pieces, no terrain, no buildings, no characters, no text, no watermark, no giant sun disk. Maintain original cloud geometry as closely as possible.
